### 01 笔记初见工坊

**面向独立创作者的笔记发布准备工具**

围绕标题、文案、封面与视频开头，分别组织图文和视频的准备流程。用户可以用自然语言表达修改要求，查看结果后继续调整，并自主决定是否采用。

我负责需求梳理、流程与交互设计，借助Codex辅助实现前端原型。案例重点介绍产品切入点、设计判断、AI交互方式，以及模型接入与发布后复盘计划。
