关注产品设计与AI产品实践，从真实使用场景出发，将需求、流程与交互落实为可体验的原型。

这里记录我的产品定位、设计思路、关键取舍与后续验证计划。

## 作品

### 01 企智通

**企业 AI 平台的普通用户端设计**

基于微软实习期间的产品实践，展示如何通过企业预设 Agent、个人 Agent 与分层交互，降低员工使用 AI 完成业务任务的门槛。

我负责登录认证、对话管理、账号管理与 Agent 管理四个模块的需求设计与迭代协同，同时承担普通用户端 UI 与交互设计。案例介绍 Agent 体系、MVP 取舍、企业安全设计，以及从原型到验收的落地过程。

[阅读企智通设计案例](cases/qizhitong.md) · [体验企智通 Demo](https://0d496e044b0944e69cc756bc75a80934.app.workbuddy.host/qzt.html)

> Demo 为本人独立整理的普通用户端前端设计展示版，与企业正式上线版本不同；未接入真实模型、企业业务数据、后端权限及安全审计能力。

### 02 笔记初见工坊

**面向独立创作者的笔记发布准备工具**

围绕标题、文案、封面与视频开头，分别组织图文和视频的准备流程。用户可以用自然语言表达修改要求，查看结果后继续调整，并自主决定是否采用。

我负责需求梳理、流程与交互设计，借助Codex辅助实现前端原型。案例重点介绍产品切入点、设计判断、AI交互方式，以及模型接入与发布后复盘计划。

[阅读完整设计案例](cases/note-first-impression.md) · [体验交互Demo](https://0d496e044b0944e69cc756bc75a80934.app.workbuddy.host/biji.html)

> 当前AI能力采用关键词规则进行Mock演示，尚未接入真实模型；原型用于展示产品方案与操作流程。
